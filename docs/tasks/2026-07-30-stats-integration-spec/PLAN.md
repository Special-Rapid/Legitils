# Plan

## Objective

Stats 機能のデータ取得・表示・通知の仕様を実装前に合意する。

## Scope

- Hypixel、Urchin、Seraph の利用可能なデータ源
- Bed Wars 開始時の対象者選定、キャッシュ、失敗処理
- Tab とローカルチャットの表示要件

## Non-goals

- このタスクでは API キー保存、HTTP 実装、Mixin の変更を行わない。
- Nick の実名復元やサーバーへ自動メッセージ送信は行わない。

## Steps

1. Meowtils の Stats パイプラインと現行 Legitils の統合点を確認する。
2. 各 API の公開可否、認証、レート制限、利用可能データを確認する。
3. MVP と将来拡張を分けた仕様案を提示し、未決定点を確定する。

## Risks

- API キーをローカル設定に保存する必要がある可能性。
- Nick は公開プロフィールと結び付けられない。
- 試合ごとの全員照会はAPIのレート制限に抵触し得る。
